# E-P5 胶片纹理与 SD 色表绑定

`film_fx.c` 处理已经开发、独占的全范围 BT.601 YUYV 帧。颗粒由当前拍摄提供种子，只改变亮度。柔光提升高光周围的亮度。光晕给高光周围加暖色、琥珀或红色，并在接近纯白处逐渐减弱。局部清晰度分别加深边缘的暗侧和提亮亮侧，保持色度及均匀区域。

光晕和柔光共享权重为 `1,2,3,4,5,4,3,2,1` 的可分离滤波。亮度大于 192 的像素提供初始高光数据。处理前取样，九行循环缓冲保留所需的原始数据。行步长可以含填充，滤波边界延用最靠边的像素。光晕和柔光需要 `9 × width` 字节。颗粒单独使用时无需暂存区。全部设为零时，图像逐字节保持一致。强度和色调无效时，处理在写入图像前退出。取消发生在入口时，图像仍可用。写入部分行后取消，调用方必须丢弃该帧。

Atrophy 的清晰度沿用同一组滤波权重。先从原始亮度按块取均值，将缩小后的帧滤波到约 96 列，再用双线性插值求每个像素的局部亮度。当前亮度与局部亮度的差决定调整方向，并在中间调增强权重。原配方强度 3 对应 32% 增益。以全尺寸合成图测试，清晰度增量暂存空间为 1,056 字节，x86-64 WSL 中单次运行耗时约 0.079 秒。

在 x86-64 WSL 内用 `cc -O2` 处理 `4608 × 3456` 合成图像，三个效果同时设为 50%，三个种子的单次耗时为 `0.141、0.142、0.149 秒`，调用方分配的暂存区为 `41,472 字节`。这是纹理本身的主机耗时。机身上的帧缓冲格式、速度、内存和预览仍需实测。

## 从 SD 卡读取纹理

新版数据包可在每组的 `INDEX.EP5` 旁放置 `FX.EP5`。缺少该文件时，效果均关闭。`ep5studio.recipe_fx.fx_sidecars` 保留第一版数据格式。`fx_sidecars_v2` 另行生成包含清晰度记录的第二版。两版沿用 Caduceus 发布目录明确指定的效果。

- 颗粒的低、中、高分别映射到 `25、50、75%`。
- 中性柔光的 1 到 5 级映射到 `20、40、60、80、100%`。
- 带色柔光按上游定义解释为光晕。1–2、3–4、5 级分别映射到 `25、50、75%`。Gold 保留琥珀色，Portra 保留暖色，CineStill 保留红色。
- 清晰度的 1 到 5 级分别对应 `12、22、32、42、52%` 增益。

当前光晕和柔光的滤波半径为 4 像素。清晰度沿用上游的亮度差和增益，模糊核与上游实现略有差异。全尺寸照片上的边缘表现仍需与参考实拍对比。

文件按小端编码。20 字节头依次为 8 字节 `EP5FXP01`、版本 `1`（u16）、记录数（u16）、数据长度（u32）、数据 CRC-32（u32）。每条 16 字节记录依次为模式（u16）、变体（u8）、保留零（u8）、色表编号（u16）、保留零（u16）、色表 CRC-32（u32）、颗粒（u8）、光晕（u8）、柔光（u8）、光晕色调（u8，暖色 0／琥珀 1／红色 2）。一组最多容纳 14 条。

第 2 版头为 `EP5FXP02`、版本 `2`，每条记录原先在变体后保留的一个字节现表示清晰度百分比。新版读取器同时支持两种格式。从已核对的三组发布包生成带清晰度的单卡包可运行以下命令。

```sh
python tools/export_recipe_color.py --combine-banks --out build/caduceus29 --with-fx-v2
```

文件工作线程应使用与已确认色表相同的挂载和分组绑定，读取并关闭 `EP5LUT/FX.EP5`。`ep5_film_fx_preset_load` 支持分段读取，完整验证后只返回与已确认模式、变体、色表编号和 CRC 一致的记录。它允许将配置与已加载色表一起发布。挂载、分组或选项更新时，调用方须一起作废旧色表和纹理设置。若任务已有完整文件，可直接调用 `ep5_film_fx_preset`。缺失、坏文件和不匹配都返回关闭设置，颜色处理仍可继续。由上层为每次拍摄设置种子。

读取完整单卡 ZIP 后，29 款配方都通过色表编号和数据 CRC 检查，并在 C 侧匹配各自的效果记录。其中 19 款启用颗粒，6 款启用带色光晕，2 款启用中性柔光，第 2 版另有 1 款启用局部清晰度。将同一合成帧通过两版卡包处理时，Atrophy 的帧结果有可测差异，Gold 帧两版逐字节一致。

本地验证命令如下。

```sh
PYTHONPATH=. python3 -m unittest discover -s tests -p 'test_film_fx.py' -v
PYTHONPATH=. python3 -m unittest discover -s tests -p 'test_recipe_fx.py' -v
```
