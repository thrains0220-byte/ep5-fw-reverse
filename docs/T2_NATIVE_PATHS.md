# T2：E-P5 1.8 原厂色彩字段与两条静态照片入口

输入固定为官方主块 SHA-256 `dfe255e4d5a43329712c1fdfd6861ee1f3ef54a268b6096628bf045d8cc590df`，CPU 映射从 `0x7e101020` 开始。下表地址是 CPU 地址，字节是该未修改主块的原字节。反汇编是**静态指令证据**；已执行的部分仅限仓库此前的 ART 参数/列表、尺寸/申请、JPEG 请求以及三处调用桥的有界模型。没有把静态可达性写成实机已运行的成片链路。

## `chContrast` 等字段：生产、复制、用途边界

路线 A 的断点已经明确：找到了可在候选窗口单次改动的 packet 字段，却**没有找到最终 ISP 消费者、经成片验证的颜色效果或共享 packet 的串行所有权**。因此不能直接改共用构造器/上下文默认值，也不能把仅修改 packet 的候选称为首版配方。下一轮追 ART packet `+156..+160` 的非日志消费者，并在验证所有权后准备一次受模式保护的单字段实验；若实际效果不足，再转路线 B 的完整 LUT 所有权与性能实验。

## 复核与下一步

在仓库根目录，对精确原始主块执行：

```bash
sha256sum data/ep5-decoded/00_0100_402c0020.decoded.bin
toolchains/mn103/bin/mn10300-elf-objdump -D -b binary -m mn10300 \
  --adjust-vma=0x7e101020 --start-address=0x7e3f55c4 --stop-address=0x7e3f58c9 \
  data/ep5-decoded/00_0100_402c0020.decoded.bin
```

同法切换上述地址区间可看到全部原字节；`docs/t2-native-paths-verification.json` 固定本次检查的主块哈希和关键位置字节。下一项**离线**工作：分别追 `0x1003` 有/无全局像素地址的两个返回出口与调用方保存、`0x1001` 的额外门控、ART packet 色彩字段的非日志消费者和共享所有权，并确定 JPEG/缩略图/ORF 如何对应文件号与实际写卡；在验证这些条件前不生成开启效果的更新包。T1 样片和 T4/T5 的安装、格式、缓存、恢复需等实机与原文件。
