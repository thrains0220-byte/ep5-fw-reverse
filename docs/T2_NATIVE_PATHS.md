# T2：E-P5 1.8 原厂色彩字段与两条静态照片入口

输入固定为官方主块 SHA-256 `dfe255e4d5a43329712c1fdfd6861ee1f3ef54a268b6096628bf045d8cc590df`，CPU 映射从 `0x7e101020` 开始。下表地址是 CPU 地址，字节是该未修改主块的原字节。反汇编是**静态指令证据**；已执行的部分仅限仓库此前的 ART 参数/列表、尺寸/申请、JPEG 请求以及三处调用桥的有界模型。没有把静态可达性写成实机已运行的成片链路。

## `chContrast` 等字段：生产、复制、用途边界

原厂字符串 `chContrast`、`chTone`、`chSaturation` 与结构偏移 `+0x55/+0x56/+0x58` 对应。`0x7e3f15ef` 和 `0x7e40f9a5` 均是读取 `+0x55` 后送日志的路径，并非 ISP 写入。字段确有更早的生产者和中间复制：

| 原厂地址 | 原字节 | 已能确认的操作 |
| --- | --- | --- |
| `0x7e3f5712` | `f8 50 55` | 共用设置构造器 `0x7e3f55c4` 的一个分支将上下文 `+17442` 的半字低位写入输出 `+0x55`；`0x7e3f571d` 对 `+17444 → +0x56`。另一分支 `0x7e3f5846` 也写 `+0x55`；`d0` 的 1–4 分支含义尚未与菜单值对应。 |
| `0x7e3f49c8` | `cd fc 0b f0 24` | JPEG 例程中调用上述共用构造器，调用前将 `d0` 清零；它同时被多条 REC/Beauty/JPEG 路线调用，直接改它或上下文默认值会影响非目标模式。此处的设置结构随后如何进入静态照片 ISP 尚未追到。 |
| `0x7e409ccd` | `f8 52 55` | ART 侧从 packet `+157/+158/+160` 复制至另一工作记录 `+0x55/+0x56/+0x58`；对应源读取在 `0x7e409cc2` 等处。它证明字段流继续，但不是色彩硬件消费。 |
| `0x7e413e88` | `f8 53 55` | 另一生产者从上下文 `+17442` 写 `+0x55`；同段 `0x7e413e8f` 写 `+0x56`，`0x7e413ea0` 写 `+0x58`。该调用所属静态拍摄条件还未锁定。 |
| `0x7e3f15ef` / `0x7e40f9a5` | `f8 43 55` / `f8 43 55` | 两处诊断读取；原厂日志名称是字段语义的依据，不是 ISP 写点。 |

路线 A 的断点已经明确：找到了字段生产与复制，却**没有找到只属于一个可选风格的参数表、最终 ISP 消费者或经成片验证的颜色效果**。因此不能在共用构造器上做“单一色彩参数补丁”并称之为首版配方。下一轮可继续在源字段 `b0+17442/17444/17466/17468` 及 ART packet `+156..+160` 的消费者上追；若仍是共享值，按计划转路线 B 的所有权与性能实验。

原厂字符串 `play_rec_raw_edit` 与 `0x7e61808d` 一带对应；这里**没有**发现它调用快门侧 `0x7e3ed7e6`。两个入口不能因都叫“显影”而合并。

回放侧断在 `0x7e13452b` 的目标任务和 `0x7e617d15` 收到的回复：尚未把 `0x1001/0x1004` 的实际消费者连到静态照片 ISP、主 JPEG 编码及卡上文件。当前不能假定回放与快门共享上述 ART buffer、同一个滤镜表或同一次 ORF，也不能用回放模型结果证明按快门直出。回放仍是 T1/T5 中固定同一 ORF 做对照的合适实验入口，是否可承载候选补丁取决于后续消费者追踪。

## 复核与下一步

在仓库根目录，对精确原始主块执行：

```bash
sha256sum data/ep5-decoded/00_0100_402c0020.decoded.bin
toolchains/mn103/bin/mn10300-elf-objdump -D -b binary -m mn10300 \
  --adjust-vma=0x7e101020 --start-address=0x7e3f55c4 --stop-address=0x7e3f58c9 \
  data/ep5-decoded/00_0100_402c0020.decoded.bin
```

同法切换上述地址区间可看到全部原字节；`docs/t2-native-paths-verification.json` 固定本次检查的主块哈希和关键位置字节。下一项**离线**工作：追 `0x1001/0x1004` 回放消息消费者、`+0x55/+0x56/+0x58` 的非日志消费者，以及快门任务的主 JPEG 写卡/ORF 对应；在找到安全局部参数点前不生成开启效果的更新包。T1 样片和 T4/T5 的安装、格式、缓存、恢复需等实机与原文件。
