# E‑P5 取景颜色与照片直出

2026-11-21。`ep5_preview_render` 为预览工作线程提供色彩处理。输入是调用者已经确认格式、能够保持只读的全范围 BT.601 YUYV 帧，输出使用独立的同尺寸后台缓冲。它用照片的同一个 17³ RGB16 采样器处理每行，支持风格强度和已经合成到色表中的十二色区调整。照片的颗粒、光晕与柔光暂留在静态照片处理中。

调用者负责给每个有效取景帧与风格组合分配非零标识，并为预览保留独立、不可变的色表，不能占用拍摄预载器的唯一读取位置。改变风格、取卡、进回放、关机或快门开始时，令当前标识失效。每行开始前 `current` 核对标识及快门优先状态。`present` 在同一次同步操作内再次核对标识和快门，再交付完整帧。后台缓冲可以有部分结果，只有 `present` 成功才可交给显示；显示归还前不能复用该缓冲。输入帧和色表的取用期限覆盖整个调用。

WSL 宿主测试用 320×240、640×480、720×480 的合成取景帧，覆盖满强度、部分强度及零强度。参照结果来自实际的 `ep5_photo_render`，逐字节比对可见像素、行尾填充和原始输入。测试还覆盖快门已持有照片色表时生成预览、第三行取消、提交前才收到快门请求、过期标识、内存重叠及容量不足。目标 MN103 对象的代码段 432 字节，数据段与 BSS 均为零，唯一外部符号为现有 `ep5_film_apply`。

三个尺寸目前均仅在宿主上通过。E-P5 液晶实际输入格式、行距、显示帧生命周期、换帧时序及快门优先信号仍须在真机验证。320×240、640×480、720×480 每个独立后台缓冲分别需要 153,600、614,400、691,200 字节（不含对齐行距），预览的独立色表另需 29,478 字节。确认设备可以借出与照片资源隔离的缓冲后，先验证最小尺寸的颜色、快门响应、菜单退出和关机，再分辨率逐级测量帧率。
