# E-P5 LUT Studio 使用说明

LUT Studio 在 Windows 上整理风格、预览照片，并给项目分配拟用的 ART 位置。**现在可以在电脑上使用；相机端读取多风格包的功能尚未发布。** 导出的开发 ZIP 不是固件，不能刷机，也不需要把文件放进 SD 卡。使用桌面程序不必连接相机。

**内置风格。** 首次启动自动加入 19 款项目原创风格：恒等校验、暖调负片（实验），以及 17 款胶片类型取向——森山风高反差黑白、金调暖负片 200/100（柯达 Gold 取向）、艳彩负片 400（UltraMax 取向）、暖彩平价负片 200（ColorPlus 取向）、柔肤人像负片 160/400（Portra 取向）、浓彩风景负片 100（Ektar 取向）、极致反转片 50（Velvia 取向）、标准反转片 100（Provia 取向）、纪实经典铬（Classic Chrome 取向）、细粒黑白 100（Acros 取向）、报道黑白 400（Tri-X 取向）、日常负片 400（Superia 取向）、电影灰调、银留漂白、交叉冲印。它们全部由公开的色彩配方程序化生成，不包含任何厂商提取数据，也不是对特定胶片的实测复刻；名称只描述视觉取向。颗粒、暗角、光晕等空间效果不在 LUT 能力范围内。网上下载的 `.cube` 仍按下方流程导入。

**启动。** 如果使用 Windows 分发包，请先完整解压，将 `EP5LUTStudio.exe` 与旁边的 `_internal` 文件夹保存在一起，双击 EXE。仓库本地打包结果位于 `build/lut-studio-dist/EP5LUTStudio/`。使用源码时可在仓库根目录运行 `python tools/run_lut_studio.py`（Windows Python 3.11、Tk、Pillow、NumPy）。默认风格库为 `%LOCALAPPDATA%\EP5LUTStudio\Library`，可用 `--library` 指定其他本地目录。

1. **导入 LUT。** 在左侧点「导入 .cube」，可以一次选多份。相同内容只保存一份。当前支持 2–65 格、归一化域的三维表，读取原文件并编译为 17³；单维 LUT、带 shaper 的复合文件和超范围数值会提示原因。详细约束见[导入规范](LUT_FORMAT_DESIGN.md)。
2. **确认颜色。** 在左侧按 LUT 作者说明选择输入和输出，并点「保存颜色声明」。只有两端均为 sRGB 才能应用到 sRGB 预览和导出项目。Panasonic V-Log/V-Gamut 等专用 LUT 可入库，但不能靠把标签改成 sRGB 来完成颜色转换。不了解来源时保留「未声明」。
3. **预览并调强度。** 默认使用程序自带的合成静物，也可点「打开照片」读本地 JPEG/PNG。左图为原图、右图为 17³ 转换结果，拖动滑块可比较同一场景。带 ICC 的照片会先转为 sRGB；未标记的照片需要明确同意后才按 sRGB 解释。预览不改原片，也不能预测机内所有 ISP 处理和压缩差异。
4. **分配 ART 位置。** 左侧选择风格，右侧选择拟用槽位、填写不超过 6 字的短名，调好强度后点「将当前风格分配到此位置」。需要迭代同一槽位时再次分配即可；切换左侧风格后可继续添加其他位置。这些是项目分配，不会修改相机 ART 菜单。
5. **保存或导出。** 「保存项目」写出 JSON，记录风格内容标识、位置、短名和强度；换电脑时需用相同原始 `.cube` 补齐当地风格库。「导出开发用风格包」生成包含原始 LUT 和项目数据的 ZIP，需要新的输出名；缺少任一绑定的 LUT 或颜色声明不兼容时不能导出。界面上的「生成刷机固件」保持禁用。

可用 `python tools/run_lut_studio.py --smoke-test` 检查 Tk、内置风格和预览能否正常启动完成。如需开发者重建 EXE，运行 `python tools/package_lut_studio.py`，将使用项目内独立构建环境，不必修改全局 Python。此前 E-P5 原生「柔彩」候选的实机结果只覆盖其固定风格，不能用来证明网上下载的任意 3D LUT 已可机内直出。
