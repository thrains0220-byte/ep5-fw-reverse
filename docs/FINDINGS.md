## CPU 地址空间

独立运行 cmdada 的 `findbase.py`，3,000 个采样字符串中 2,230 个支持基址 `0x7e101020`。新的精确输入扫描进一步得到：

- 39,456 个 MOV-immediate 指令特征指向完整、以零结束的 ASCII 字符串。
- 覆盖 31,396 个不同字符串起点。
- 把容器头的 `0x402c0000` 用作 CPU 基址，仅匹配 1 处。

原生入口指令可顺畅反汇编，写入 `0x7e110020` 等中断向量，并将 flash 源 `0x402cf000` 读到 `0xbe110000`。该 uncached 目的地址与 `0x7e110000` 对应。这是区分更新包地址、CPU 代码地址和 RAM 别名的额外依据。

这些计数本身不是代码可达性证明；已使用到的诊断路径另以真实指令执行核对。

### 原版指令测试的范围

`tools/native_probe.py` 固定校验主程序哈希，复用固定提交的 MN103 CPU 指令引擎。代码映像只读；仅允许写入有界的合成栈及参数 RAM；未知访问或非对齐访问停止执行。

两类测试：

1. **独立启动分支**：F971 服务返回 0/1；原版分支分别发起 0/1 次 Wi-Fi 初始化调用。延时、参数服务和 Wi-Fi 初始化是模型。
2. **连接的 CSV 路径**：原版解析 `Wifi shell,0xF971,1,0/1`，原版建立覆盖索引，原版 getter 读回，原版启动分支使用覆盖值；随后原版清除覆盖，回到合成基础记录中的零值。该类的解析、覆盖及 getter 没有用主机算法替代。

模型没有执行文件系统发现、实际导入调度、并发启动、无线硬件、真实 socket 通信或 ISP。基础索引中人为提供了一条值为 0 的 F971，用于检查覆盖清除；这不证明所有相机的出厂参数都为 0。离线路径未触及 flash，不代表整个调试服务的所有命令都只读。

## 色彩核心

原创 `firmware/lut.c` 是无动态分配的 17³ RGB16 三线性插值核心；输入为已确认颜色编码的 RGB8，由未来的机身适配层负责提供。它没有实现 ORF 解码、YCC 转换或 JPEG 保存。

主机测试覆盖恒等、端点、跨通道插值、无效尺寸、容量、行填充、LUT 完整性和全尺寸运行。4608×3456 合成输入为 47,775,744 字节，恒等处理后 SHA-256 不变；实验风格改变输出而不改变尺寸。主机运行时间不能用于预测相机处理时间。

### MN103 编译代码验证

本机从 GNU 校验过的 GCC 14.3.0 源码构建 `mn10300-elf` C 编译器。未改变 `firmware/lut.c`，以 `-O2 -mno-am33 -ffreestanding` 编译；测试调用者和尾部取指填充合计 783 字节。普通 MN103 与 AM33-2 两种反汇编结果一致。

`tools/check_mn103_lut.py` 将这份代码放入合成只读代码区，输入 LUT 只读，写入仅允许像素缓冲区、返回值和栈。像素计算完全由编译后的指令完成；唯一停止钩子在测试结束标记，不替代像素处理。两行共 256 个 RGB 像素，包含全部 8 位代码值、行间填充和前后保护字节。

## 离线接入准备续作

`firmware/film.[ch]` 现已实现有界原地 YUYV 处理、强度 0..256、每最多 16 行的进度/取消，以及从独立有界映射生成裁切视图。LUT 采样提取为共享 RGB16 核心，原 RGB8 接口测试仍通过。内部不分配整幅 RGB 副本；保留输入 YCC 残差，恒等 LUT 在覆盖所有 Cb/Cr 组合的合成图上逐字节保持输入。4608×3456 图像的非恒等处理及每行填充保护通过主机测试。

候选仅显式支持 BT.601 全范围的 Y0/Cb/Y1/Cr；没有把它标成 E-P5 实测色彩编码。转换到 RGB 时对 LUT 域外颜色裁切，但只把 LUT 引起的差值加回原始 YCC，所以恒等变换不引入重建裁切。真实机身校色、色域、JPEG 压缩、RAW 处理仍未验证。

### 原厂描述符读取

直接执行原版 `0x7e40fba4` 的 58 条指令，调用帧 `[a2],8`。只读合成描述符填入独立标记，原厂代码按顺序读出 `pAddress/+0`、`pAddressC/+4`、`usDataFormat/+8`、`usMemHw/+10`、`usUseHw/+12`、`usUseVw/+14`、`usAreaHw/+16`、`usAreaVw/+18`、`usOffsetH/+20`、`usOffsetV/+22`、`usCenterH/+24`、`usCenterV/+26` 及 `dummy/+28`，模型日志逐项核对。栈与非易失寄存器保持。日志函数是模型，图像描述符读取是原始指令；不涉及真实像素或拍摄任务。

`0x7e3f4884` 的 `REC MISC YC2JPG` 候选在调用点 `0x7e3f2a13` 接收 `a0` 上下文及 `a1` 独立输入，帧 `[d2,d3,a2,a3],16`。该输入结构并非上述通用 32 字节描述符。不能直接复制 E-M10 `ctx→source descriptor` 的接口或截获方式。
