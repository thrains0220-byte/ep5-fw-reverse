# 网上下载的 .cube 怎样进入 E-P5 风格库

这是桌面导入和导出的接口设计，不是新固件的安装说明。桌面库可以保存完整三维 LUT；原厂 ART 色度曲线只能实现其中一部分效果。对同一个文件，应分别告诉用户「可在电脑预览」「可编译为实验核心的数据」「有可验证的机内近似」，三者不是同一个承诺。

## 仓库现有的约定

- [compile_lut.py](../tools/compile_lut.py) 的 `compile_cube(text)` 目前只接受 17³、归一化域、有限且在 [0,1] 内的三个输出值；每格输出用 Python `round(v*65535)` 量化。现有 1 MB 文本上限不适合 65³。已有脚本与调用者可保留这一严格入口；桌面库单独接收更多边长。
- [lut.c](../firmware/lut.c) 使用无头的 29,478 字节表，17³ 个格点，每个格点按 RGB 排列，各为小端 uint16。R 轴最快、G 次之、B 最慢；按三线性插值逐轴舍入。[现有测试](../tests/test_lut.py)已包括恒等、RGB 换轴和跨通道变换。裸数据没有风格名、颜色空间或 ART 槽号。
- [film.c](../firmware/film.c) 把有符号 RGB 变化乘以 `amount/256`；0 原样通过、256 全强度。该 YUYV 适配器**假设** BT.601 全范围、4:2:2 色差共享；它不是 E-P5 图像缓冲区颜色编码的证明。RC2 真机样片来自原厂色度曲线路径，没有执行这个软件 3D 核心。

## 导入合同

| 输入项 | 建议第一版行为 |
| --- | --- |
| 格式 | 本地文本 `.cube`，UTF-8（可带 BOM），兼容 LF/CRLF，支持空白行、引号外的 `#` 注释和可选 `TITLE`。标题是展示文字，不用于构造文件路径。未知、重复或数据之后出现的头字段报错并给出行号。 |
| 三维规则表 | 一个 `LUT_3D_SIZE N`，整数 2 ≤ N ≤ 65，恰好 N³ 行，每行三个十进制或科学记数法浮点值。支持 2、16、17、32、33、64、65 等，不能只接受 2 的幂加一。文本行序为 B/G/R 三重循环；第 `(b*N+g)*N+r` 行为该格点的输出 RGB。 |
| 输入数值域 | 默认各通道 [0,1]。直接导出路径接受缺省或显式 `DOMAIN_MIN 0 0 0`、`DOMAIN_MAX 1 1 1`；可兼容 Resolve 独立 3D 表的明确等价写法 `LUT_3D_INPUT_RANGE 0 1`，两套写法同时出现时拒绝。非单位域第一版提示「当前不支持该输入域」，不要忽略、擅自归一化或推断为某种 Log。将来专门实现非单位域时应显式定义输入坐标、域外处理和空间变换顺序。 |
| 输出数值 | 恰好三个有限 [0,1] 样本。遇到 NaN、Inf、负值或大于 1 要报错，不能自动裁剪后继续；有效的 HDR/超范围 LUT 可能因此不适用于本目标。 |
| 1D / 复合 LUT | 第一版明确拒绝 `LUT_1D_SIZE`、1D shaper + 3D、`LUT_1D_INPUT_RANGE` 或多表串联。不要跳过 shaper 只读后半段。未来可单独实现三路 1D 各自插值后再进 3D 的组合。不同 `.cube` 方言确有此区分，见 [OpenColorIO 格式说明](https://opencolorio.readthedocs.io/en/latest/guides/using_ocio/using_ocio.html)。 |
| 限界 | 先限制原文件字节数（建议 32 MiB）及单行长度（建议 4 KiB），边读边检查精确计数，最多 274,625 个节点。数值表存连续数组 [B,G,R,3]，不用数十万个 Python 子列表；验证再量化。保留文件 SHA-256、标题、边长、域和原始文件，避免反复重采样。 |

库内随文件另存来源说明、作者/许可（如有）、**输入**编码和**输出**编码，两端都不可省略。首版可直接作用于 E-P5 JPEG 的目标合同是「显示参照、非线性的 sRGB → 显示参照、非线性的 sRGB」。`Unknown` 可保存，要求用户查作者说明再确认；文件名、标题和 0–1 数值域均不能识别颜色空间。Rec.709 gamma 2.4、Log、linear 或厂商专用输入不能自动当作 sRGB。比如[松下官方的 V-Log/V-Gamut LUT](https://av.jpn.support.panasonic.com/support/global/cs/dsc/download/lut/index.html)有指定输入，不能直接套在 E-P5 的 sRGB 成片上称作同一种风格。处理已有 JPEG 也无法恢复当初拍摄场景的线性动态范围。

## 重采样、预览、强度

1. 在目标格点 `(r/16,g/16,b/16)` 查源 N³ 表。坐标乘 `N-1`，取邻近八点，依 R→G→B 三线性插值；端点 1 用末格。用 float64 做中间运算，仅最终量化，保持与 Python round 相同的 ties-to-even 规则。对已合法 17³ 文件，输出应与旧编译器逐字节一致。65³ 降成 17³ 可能丢失局部细节；保留原表，预览可切换原表、17³ 结果、原厂曲线结果。
2. 要复现核心预览，RGB8 输入每个通道乘 257。每一维 `pos=code*16`，商/余数以 65535 为除数；最后端点映射为末单元加满分数。8 个邻点按 R→G→B 三次嵌套使用 `(a*(65535-f)+b*f+32767)//65535`。数组运算显式使用足够宽的整数，避免 NumPy uint16 溢出。输出 RGB8 为 `(rgb16+128)//257`。
3. 用户强度 0–100%，存储整数 `q8=(percent*256+50)//100`。在输入编码域混合一次 `in16+round_signed((out16-in16)*q8/256)`；`round_signed` 对等距值远离零，与 film.c 相同。0% 直接旁路。建议保持原表原样，强度跟随风格项目保存；目标没有强度参数才在导出时烘焙一次，并记录已烘焙。预览用同一份编译结果和同一个强度；原厂曲线近似要另算，不能对强度重复处理。
4. 读取预览照片时用 [Pillow ImageCms](https://pillow.readthedocs.io/en/stable/reference/ImageCms.html) 将**已标识、能转换**的嵌入 ICC 转成工作 sRGB；标准 sRGB EXIF 可直接读。缺少可靠标记时提示用户明确选择「假定 sRGB」，识别出 Adobe RGB 等其他空间时不要默认用 sRGB。对预览应用 Exif 旋转，保留原文件。桌面 RGB 合成能验证色表和色彩变化方向，不能精确代表机内 ISP、4:2:2 抽样和编码结果。将未来的「原生曲线近似」和「完整 3D LUT」并排时要清楚标名。

## 接口与验收建议

建议保持 `parse_cube(source)`（语法、采样网格及数值域）、`compile_rgb17(grid, color_contract)`（小端字节和编译参数）、`preview_rgb8(image, lut, strength_q8)`（应用精确核心算法）、`fit_native_art(grid, slot_contract, strength_q8)`（受限的原生拟合及误差）相互独立。名字可随应用结构调整。下载的风格是数据；其文件名、标题、网址不能充当命令、代码或输出路径。

原厂两条一维色差曲线的能力不足以实现任意 3D LUT：例如黑白反转、依赖亮度的肤色选择、跨通道换色。即使可拟合，也要比较**原始 LUT 与最终量化后的原生曲线**，报告测试采用的颜色空间、网格、误差和不可表达部分；误差过大不交付为相机风格。只有对特定硬件槽的 selector、内存引用和菜单对应关系均已验证时才能写入该槽。一次生成多个 17³ 表不会产生多个可运行 ART 选项。

建议用以下实际差异验收：2³ 恒等和换轴应正确区分红蓝；16³ 非对称跨通道仿射表可验证非对齐网格坐标；33³ 或 65³ 带锐弯的表应体现降采样误差；17³ 旧表 SHA 应保持；全部 256 个码值经过恒等表、强度为 0 或 100 的结果应符合核心；非法计数/类型/方言/域应能指出原因；同一场景中显示 LUT 目标和原生近似要留存两份可区别的输出。矩阵行序可对照 [colour 的 IRIDAS 实现](https://github.com/colour-science/colour/blob/develop/colour/io/luts/iridas_cube.py)。

## 本机桌面条件

检查时 Windows x64 默认 Python 为 3.11.9；可用 Tcl/Tk 8.6.12、pythonw、Pillow 12.3.0（含 ImageCms）、NumPy 2.4.6、PySide6 6.12.0、colour-science 0.4.7。PyInstaller、cx_Freeze、Nuitka、PyQt6、PyOpenColorIO 未在这个解释器中找到。核对环境时未安装软件。桌面原型可用 Tk、Pillow、NumPy，配合无需终端的 pythonw 启动；如交付单独 EXE，应另用项目构建环境并验证在没有 Python 的 Windows 上启动、打开含中文路径的文件、导入和预览。如用 PyInstaller，可先用便于诊断的 [one-folder 模式](https://pyinstaller.org/en/stable/usage.html)。
