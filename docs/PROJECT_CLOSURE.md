# 项目结项说明（2026-10-23）

> 本项目到此收尾。下面是**最终状态**的诚实汇总：做到了什么、没做到什么、为什么、以及如果有人要接着做，从哪里下手。

---

## 1. 最终结论（一页版）

| 问题 | 答案 |
|---|---|
| 固件容器格式 | **100% 破解**，`decode → encode` 逐字节可逆，块校验和为加法 sum32 |
| 能否做出**能刷、不变砖**的固件补丁 | **能**。已有一条用户实机验证通过的补丁（AF 步数上限解除） |
| 能否**改滤镜的表现** | **能**。13 个艺术滤镜的像素实现都在块 0（`.BIN` 内） |
| 能否**改菜单显示名** | **能**。菜单名在块 1 的语言资源包里（UTF-16LE，等长可改） |
| 能否**凭空新增一个 ART 菜单项** | **不能**（在只拿到 `.BIN` 的前提下）。「菜单显示哪几项」的选择表在 `0x7E` 区（另一侧存储），而该区内容既不在官方更新包里、官方也不下发 |
| 官方渠道能否拿到 `0x7E` 区 | **不能**。OMSRV 41 组请求变体只返回 1 个 `.BIN`；PC 更新器本体在奥记 CDN 已 404 |
| 唯一能拿到 `0x7E` 区的办法 | ① 拆机读并口 NOR（型号候选见 §5）；② 让相机自己 dump（块 0 内有完整调试 shell，入口未找到） |

## 2. 已经被实机验证的东西

1. **卡刷通路**（第 26 轮）：SD 卡根下 `DCOLYMP\E1089999.BIN` = 官方 `.BIN` 原样改名。
   插卡 → 关机 → 按住 OK + 电源 ON → AF 灯常亮(认文件)/快闪(在写)/灯灭(完成)。
2. **AF 驱动步数上限解除**（第 24 轮）：只改 4 个 payload 字节 + 3 个校验和字节。
   用户已刷入，相机正常、拍照正常。SHA-256 `209379198f02539abe820a6ab9e9254f5ac70e972f291fc7e3b6e938e03daf2f`。
3. **补丁工厂**（`tools/make_patched_firmware.py`）：按唯一字节模式打补丁 → 重算块校验和 → 重打包 → 回读自检。
   命中数 ≠ 期望值直接拒绝出包。**改过的固件不入库**，仓库只留配方。

## 3. 关于艺术滤镜，修正过的三次结论（留给后来人避坑）

1. 第 20/25 轮：「滤镜算法在 mask ROM，`.BIN` 里改不了」——**错的**。
   13 个滤镜实现（`art_filter_XX` / `art_effect_XX`，ID 是**十六进制**）就在块 0。
   错的只是「菜单清单/注册表在 ROM」。
2. 第 22/27/28 轮：「ART 照片 10 项、录像 4 项」——**错的**（用户实机：照片 12 项，录像同为 12 项）。
   连带作废了 C1/C2/C3/D2/D3 四个配方。
3. 第 28 轮中途：「菜单名在 ROM」——**也错的**。菜单名在块 1 的语言资源包里。

**教训**：本项目里最大的坑不是技术难度，而是**用 ROM 指针的存在与否去推断「能不能改」**，
以及**在没有实机确认的情况下把推断当结论往下推**。`0x7E` 区既可能在 ROM 里，也可能在运行时被填进 RAM。

## 5. 如果要接着做

**A. 拿到 `0x7E` 区（唯一能新增菜单项的路）**
- 并口 NOR 候选：`S29PL064J` / `SST39VF6402` / `LH28F640BFG` / `TE28F640J3D` /
  `S29GL064A` / `K8P2815UQB(MirrorBit)` / `MX29GL320ET`（64 Mbit=8MB 或 32 Mbit=4MB）
- 块 0 内调试 shell 能力：`dump` / `psave` / `pload` / `erase` / `clear` /
  `fmem` / `partinfo` / `tnan ifread|ifwrite|iferase` / `oly fmem <addr> <size> <mode>`
  + 「Major ROM Address」分区表（`adj/mode0/mode1/param0/param1/lensfav/usr/pict/osd/artfill/arteffe/sound`）
  → **入口条件未知**，是最值得先啃的线索

**B. 不用 ROM 也能做的**
- 改写已有滤镜的表现（13 个实现在块 0）：定位每个滤镜的增益/色调曲线表
  （候选：`0x402E6FE0` 32 KB 单调斜坡、`0x402EF048` 3992 B），替换成自定义 LUT
- 菜单显示名改写（块 1 UTF-16LE，等长覆盖）→ 自定义滤镜命名
- 计算摄影限制常量（R-5，89,295 个 `CMP #imm` 点 / 22,471 函数，尚未按子系统收敛）

**C. 方法论备忘**
- MN10300 `CALL` 编码 = `cd` + u32（**低 16 位是有符号位移**，高字节是参数/帧大小）；
  Ghidra 的引用分析在本工程不完整，**必须自己按字节扫**。
- Ghidra 运行地址 = 块内文件偏移 + 块基址（E-P5 块 0 = `0x402C0000`）。
- 常用指令：`fc dc`=MOV#imm32,A0；`fc ad`=MOV#imm32,A13；`2d XX XX`=MOV#imm16,D1；
  `80 XX`=MOV#imm8,D0；`cb`=NOP；`c8/c9/ca XX`=BEQ/BNE/BRA。
