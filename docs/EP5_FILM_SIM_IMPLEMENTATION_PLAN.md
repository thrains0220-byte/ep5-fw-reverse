# E-P5 高质量胶片模拟：实现方案（修正版）

日期：2026-11-14
前提：safe-7 已真机验收通过；用户反馈「借 ART 实现的胶片模拟效果不够好」，想要 Caduceus 级别的
胶片色彩 + HSLFX + SD looks + 颗粒 + halation，并指出 PEN-F 是 TruePic VII（2015），比 E-P7 更接近 E-P5。

---

## 0. 先纠正我之前的两个错误

1. **PEN-F 是 TruePic VII（2015），不是 VIII。** 只有 E-P7/E-M5 III 是 VIII。
   E-P5 是 TruePic VI（2013）。所以 PEN-F 与 E-P5 只差一代，**参考价值确实比 E-P7 大**。
2. **我之前说「E-P5 只能做色度曲线、效果不好」是低估了。** 本机核查发现 E-P5 有完整的
   **色彩矩阵 + 饱和增益 + gamma/tone 曲线**引擎（普通照片模式），以及 ART 的 16 节点色度曲线。
   之前只改了 ART 的 Cb/Cr 两条曲线，**没动色彩矩阵和 tone**，所以色彩单薄、没有胶片的「厚度」。

---

## 1. 为什么现在的 ART 胶片色「效果不好」（根因）

我们 safe-7 只改了每个 ART 槽的 **Cb/Cr 两条 16 节点色度曲线**（49 字节×2）。这只能做：
- 整体饱和度的非线性拉伸/压缩。

它**做不到**真正胶片模拟需要的：
- **色相旋转**（胶片红偏橙、绿偏青、蓝偏紫）——需要色彩矩阵或逐色 HSL；
- **亮度 tone 曲线**（胶片 S 曲线、阴影抬升、高光滚降）——需要 gamma 表；
- **逐色独立调整**（肤色保护、天空压蓝）——需要 12 扇区 HSL 或矩阵；
- **颗粒 / halation / bloom**——需要空间效果路径。

所以单靠色度曲线，看起来就是「原厂 ART 加了点饱和」，没有胶片味。**这是方法局限，不是 E-P5 硬件不行。**

---

## 2. E-P5 真实色彩硬件（本机已核实的落点）

| 引擎 | 地址 / 证据 | 能做什么 | 对应 Caduceus |
|---|---|---|---|
| **普通模式色彩矩阵** | 0x7e454190 起，3×3 u16 ×256 定点；多组（Natural/Vivid/Portrait…） | 色相旋转、通道增益、白平衡偏移 | film look 的矩阵部分 |
| **饱和增益 ramp** | 同区 280/304/328/352/384、304/352/400/448/512 | 分级饱和（阴影/中间/高光） | 减色饱和 |
| **tone/gamma 曲线** | 同区 15,25,30…160,400,800 ramp；iFinish `rgbgamma`/`ygamma`/`nv`/`spc`（0x7e3b02f0 dump） | S 曲线、阴影/高光、对比 | tone curve / Blacks / Whites |
| **ART 16 节点色度曲线** | 0x7e438a28 起 26 张（13 模式×2 轴） | 非线性饱和（已用） | look 色彩辅助 |
| **CMIO 色彩引擎** | 0x7e573000 数据块（magic CMIO）；0x7e21c42c 代码 | 色彩处理调度 | HSL 表上传 |
| **颗粒硬件** | `art_filter_06_rough_monochrome`、`art_random_generator32`、mask 曲线 | 亮度颗粒（现仅 gate 给粗糙单色） | grain |
| **效果函数（空间）** | soft_focus/pinhole/diorama 等 13 个效果指针 | blur/blend（halation/bloom 的潜在路径） | halation / bloom |
| **Color Creator** | 0x7ec42803 judge；OSD 0x364cb4 | 原生色相/饱和环 | 色彩波轮（独立模式） |
| **My Set 1–4** | OSD 0x2cefb0 | 存整套配方 | COLOR1–4 槽宿主 |

**关键结论：E-P5 有矩阵 + gamma + 色度曲线三层色彩控制，足以做出有「厚度」的胶片色。**
之前没用矩阵和 gamma，是效果差的直接原因。

## 3. 分阶段实现方案（按「效果提升 / 风险 / 工作量」排序）

### 阶段 A：把现有 ART 胶片色做「厚」（最高优先，纯数据，风险同 RC2）
**目标**：不新增宿主，直接提升 safe-7 的 7 槽观感。
**做法**：每个 ART 槽除了 Cb/Cr 曲线，再改它对应的**色彩矩阵 + tone gamma**。
- 定位每个 ART 模式在 CMIO 块里的矩阵/gamma 指针（0x7e22a023 分派表已找到）。
- 用真正的胶片 3×3 矩阵（Velvia 高饱和偏冷、Portra 暖肤、Gold 暖金、CineStill 钨丝偏青）替换。
- 加胶片 S 曲线 tone（阴影微抬、高光滚降）。
**验证**：探针证明只改目标模式；真机拍同一静物对比 safe-7。
**预期**：色彩立刻有胶片味，暗角仍在（针孔效果保留）。
**风险**：低（纯数据，RC2 同类）。

### 阶段 B：普通照片模式（P/A/S/M）胶片直出（高优先，纯数据）
**目标**：不进 ART 也能胶片直出，保留最高画质、无暗角。
**做法**：改 Natural/Vivid/Portrait/Monotone 的矩阵 + 饱和 ramp + iFinish gamma。
- 把 0x7e454190 区的矩阵/gamma 按胶片配方重写。
- 用 My Set 1–4 存 4 套胶片配方，一键召回。
**验证**：探针证明只改目标 colortone；真机 P 档对比。
**预期**：P 档直接出胶片色，无 ART 副作用，画质最好。
**风险**：低-中（需精确锁定每个 colortone 的表，避免串模式）。

### 阶段 C：SD 卡热换 LUT / looks（松下 S9 体验，需一次代码补丁）
**目标**：卡上放 look 文件，半按快门加载，换风格不重刷。
**做法**：我们的 mode-3 运行时 + Caduceus sd_bundles_v3 安全模式（不写 loaded image、malloc 池发布句柄）。
- E-P5 fileif API 已确认（FILECLBK / fileif_fopen/fread）。
- look 文件 = 矩阵 + gamma + 色度曲线的打包（比纯 .cube 更贴合 E-P5 硬件）。
- 桌面工具把任意 .cube **拟合**成 E-P5 的矩阵+gamma+曲线（不是直接塞 3D LUT，硬件没有 3D LUT 单元）。
**验证**：fileif 钩子 + 静态像素契约真机取证。
**风险**：中（代码补丁，但 boot 不读卡，坏文件=回原厂）。

### 阶段 D：颗粒（中优先，需代码补丁）
**目标**：彩色照片加胶片颗粒。
**做法**：E-P5 颗粒硬件现仅 gate 给粗糙单色。借鉴 Caduceus grain_cpu：
- 要么打开彩色颗粒门（找 E-P5 的 mode gate），要么用 CPU 在效果路径加亮度颗粒。
**风险**：中-高（效果架构不同，需逆向落点）。

### 阶段 E：halation / bloom（低优先， hardest）
**目标**：CineStill 红晕、柔光。
**做法**：复用 E-P5 soft_focus 的 blur/blend 路径，加高光键 + 红色 tint。
**风险**：高（Caduceus 在 E-P7 上也未完全定位；E-P5 需从头逆向）。

### 阶段 F：机内 HSLFX 编辑器 / 色彩波轮（最后， hardest）
**目标**：机内逐色 H/S/L 编辑。
**现实**：E-P5 没有 COLOR profile UI 宿主。两条路：
- **F1（推荐）**：用原生 Color Creator 当波轮 + 我们的矩阵/gamma 配方，不新建 UI。
- **F2（重）**：新建编辑器 UI + 设置存储 + 校验器（等于重写 Caduceus GUI 层，砖风险高，不建议现在做）。

---

## 4. 关于「直接用上网上分享的 .cube LUT」

E-P5 **没有 3D LUT 硬件单元**（不像松下 S9 / 富士）。所以不能把 .cube 原样塞进去。
但可以用桌面工具把 .cube **拟合**成 E-P5 能执行的三层：
1. 3×3 色彩矩阵（色相旋转 / 通道增益）；
2. 亮度 gamma + Cb/Cr 色度曲线（tone + 饱和）；
3. 逐色近似（用矩阵 + 分级饱和逼近）。

拟合会有误差（尤其强色相旋转的 LUT），但常见胶片 LUT（Velvia/Portra/Gold/CineStill）拟合度足够好。
我们已有 `tools/cube_to_hq.py`（Cb/Cr 投影拟合），需扩展为「矩阵 + gamma + 曲线」联合拟合。
**这是「用上网上 LUT」的现实路径，且保留相机高画质（ISP 原生处理，非后期）。**

---

## 5. 建议的执行顺序与里程碑

1. **A：ART 矩阵+gamma 增厚** → 真机对比，确认胶片味提升。（最快见效）
2. **B：P/A/S/M 胶片直出 + My Set 配方** → 无暗角高画质直出。（最实用）
3. **C：SD 热换 look + .cube 拟合工具** → 松下 S9 体验。（最灵活）
4. **D：颗粒** → 胶片质感。
5. **E/F：halation / 编辑器** → 按需。

每阶段遵守防砖硬约束：探针证明只改目标模式、共享/录像回原厂、效果指针非零；
新配方未真机实拍前只标 candidate；**清零效果指针=已证实黑屏，禁止再上机**。
