# PEN E-P5 1.8「柔彩」固件候选 1

**适用 Olympus PEN E-P5。该包已构建并完成离线指令验证，尚未在相机上刷入、拍照或回刷。** 它占用机身原有的「针孔相机 I」照片选项。预期成片保留原厂针孔效果，降低鲜艳颜色的浓度，中性色阶附近变化较小。两条原生一维色度 LUT 直接参与机身的图像处理参数生成。首版固定一个风格。实际色彩、取景预览与最终 JPEG 是否一致，仍须实拍。

## 拍摄与对照

1. 安装前先用当前固件拍一张含灰色、肤色和鲜艳物体的静物，同一光线下固定曝光和白平衡。保存「针孔相机 I」和普通模式的全尺寸 RAW+JPEG 作为对照。若机身已有历史改版，记录来源。候选包按官方 1.8 全包构建，刷入会替换历史改动。
2. 在候选固件上将拨盘转到 **ART → 针孔相机**，按右方向键选择 **I**，按 OK 或半按快门确认。设为 **4:3、最大尺寸、RAW+JPEG**，单拍。卡上应产生同次拍摄的 ORF 和 4608 × 3456 JPEG。普通拍摄可切回 P/A/S/M 并选择 Natural 等普通照片风格。菜单仍显示原厂名称。判断直出效果应查看卡上的主 JPEG，电脑重新显影 ORF 可能呈现另一种颜色。
3. 下载卡上原文件，完整解码 JPEG 和 ORF，核对尺寸及文件编号。对比安装前后的针孔 I，检查高饱和色块和灰阶。再检验普通模式、针孔 II/III、再开机及再次拍摄。若只看到预览变化、主 JPEG 没有变化，或者出现写卡异常，记录模式、设置、卡和原文件，停止使用这个候选。机内 RAW 数据编辑如能重复显影同一份 ORF，可以排除重拍导致的曝光差异。[原厂中文说明书，第 31、71 页](https://download.omsystem.com/pages/inst/ep5/manual_ep5_CHS.pdf) · [机型规格与滤镜名称](https://om-digitalsolutions.cn/product/dslr/ep5/spec.html)

## 试验机安装与恢复

- 压缩包中已放好 `DCOLYMP/E1089999.BIN`。在电脑解压后，核对固件 **44,826,624 字节**，SHA-256 为 `2f3eb6cd7d9b0c4bdd29414174e02fe850e26ed9dae482ad55a076559075243f`。在解压目录可执行 `sha256sum -c SHA256SUMS`。Windows PowerShell 可执行 `Get-FileHash .\DCOLYMP\E1089999.BIN -Algorithm SHA256`。先备份照片，把单独的官方 1.8 原包留在电脑上。
- 项目主分支记录了 E-P5 上的 SD 更新经验，使用的是官方 1.8 及另一款 AF 补丁。用于本候选的机身应允许承担首次验证风险。使用电量充足的电池及相机可识别的备份卡，将**整个 DCOLYMP 文件夹放到卡根目录**，确认卡上文件哈希仍与上面一致。关机插卡，按住 OK 并打开电源。按原记录，前部 AF 辅助灯先常亮，随后快速闪烁，最后熄灭。快闪表示正在写入，期间不要断电或取卡。观察到上述完整顺序并确认灯已熄灭后，才关机换回拍摄卡。仅看到版本号 1.8 或灯从未亮起，都不足以判定安装成功。[既有 E-P5 实机记录](https://github.com/thrains0220-byte/ep5-fw-reverse/blob/10701605b3cacb9e7f9ded1c4cd65016e13b22aa/docs/PROJECT_CLOSURE.md)
- 如果仍可进入已知的 SD 更新入口，可用单独的测试卡将**官方原版 E-P5 1.8** 按同一路径放置，回刷后重新拍原厂对照。本工作区的原包位于 `data/ep5-stock/OLY_E_108_1800_0000_0000.BIN`。若使用下方项目归档中同名的 `.BIN.lzma`，须先解压为 BIN，再核对哈希并改卡上文件名。原版整包 SHA-256 为 `cc59a4e13b3bf6c46405bd396975cb9c93a7634b7a4a36822259b1fc498b5cfd`。本候选尚未完成一次实机恢复演练。如果机身和更新入口都不能启动，USB 数据线或恢复文件本身无法保证救回。[项目的原版文件记录](https://github.com/thrains0220-byte/ep5-fw-reverse/tree/10701605b3cacb9e7f9ded1c4cd65016e13b22aa/firmware/pre_fix) · [OM SYSTEM 官方机身更新目录](https://support.jp.omsystem.com/en/support/imsg/digicamera/download/software/firm/e1/)

## 固件差异与验证边界

| 项目 | 结果 |
| --- | --- |
| 色彩映射 | 针孔 I（照片模式 73）的两个色度轴使用同一条分段曲线。输入 0、64、128、192、255 对应输出 40、74、128、182、215。128 保持中性，两端比中段压缩得更多。未改变亮度曲线，无额外整帧 CPU 循环。 |
| 修改范围 | 主块的一对 49 字节原厂表、一个录像模式跳转表项和四处原厂数据读取地址。主块实际不同的字节共 48 个，另有 4 个主块校验字节变化。其余三块逐字节相同。无新增可执行代码、代码空洞依赖或额外任务。 |
| 录像与其他模式 | 照片 73 和录像 82 原来共用曲线。把 82 改指内容相同的原厂表。对最终包重新解包，在固定辅助输入下执行原厂选择器，遍历 256 个模式号，各核对 34 个驱动参数字。仅 73 的参数有变化。录像准备代码另有一条路径也会传入 73，在已测录像状态下只排入原厂针孔滤镜。其他录像状态与取景画面是否受影响仍须上机核对。 |
| 共享参数副本 | 原厂会把所有风格的曲线复制进同一个 CMIO 参数记录。四处地址改指原有的相同数据。执行最终主块的完整原厂初始化，17,337 条指令得到的 5,764 字节与原版逐字节一致。 |
| 成片路径 | 在原厂和候选主程序上，分别输入两组模拟拍摄状态，执行原厂拍照参数构造、ART 资格判断及任务列表选择。两条 RAW→YC 路径都构造了类型 4 的图像处理作业。将作业交给原厂驱动后，针孔 I/II/III 分别选到 73/106/108。探针模拟了 RAW 句柄和缓冲区，实际 ISP、JPEG 编码及 ORF 写卡仍待相机验证。 |
| 整包 | 官方 1.8 原包往返重建一致。复查输出四块校验、长度、主块预期差异及未修改块。输出解码主块 SHA-256 为 `10fac02b381f8253b039cc0fd297d2947544111cdd48deb67f67458b36f34b01`。 |

效果完全使用 E-P5 的内置色度处理。旧的 17³ 三维 LUT 引擎和四处 ART 实验调用桥均未写入本包。E-M10 的作者记录了同代硬件色度表的布局，可作交叉参考。本包的参数、地址和模式对照均基于 E-P5 原版。[E-M10 的硬件色度表记录](https://github.com/cmdada/em10-fw/blob/6adb3bef36239859ae3fcd94b0dbb7db6de6ffa1/notes/plugins.md)

## 从原版本地重建

在仓库根目录准备好 README 指定的 `external/oly_fw_analysis` 后运行。构建只需 Python 和固定版本容器工具。指定一个尚未存在的本地输出目录。

```bash
python3 tools/build_native_film.py data/ep5-stock/OLY_E_108_1800_0000_0000.BIN --revision 1 --out build/soft-chrome-1
(cd build/soft-chrome-1 && sha256sum -c SHA256SUMS)
```

重建文件的哈希应与本页公布的候选哈希完全相同。只有在 E-P5 上验证安装、实际全尺寸风格 JPEG、同次 ORF、关闭效果和原厂恢复后，才有依据把此候选标为真机可用版。

## ART 菜单候选 2

按机主选择，保留原厂 ART 操作。候选 2 在简体和繁体的滤镜列表文字中标明「针孔/柔彩I」与「針孔/柔彩I」。在 ART 列表内按右方向键选 I，按 OK 或半按快门确认。拍摄中可按 OK 再次打开原厂 ART 菜单。II、III 沿用原厂效果。[原厂 E-P5 中文说明书，第 31 页](https://download.omsystem.com/pages/inst/ep5/manual_ep5_CHS.pdf)

从官方 1.8 原版重新构建。当前默认版本为 2，生成的 BIN 为 44,826,624 字节，SHA-256 为 `90a63cd0b191f0d0cfdf344b2129723af07f6969d1d6368b8e2216a2019c1229`。
