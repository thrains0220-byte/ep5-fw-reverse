# E-P5 1.8 原厂免刷色彩核查

2026-11-21。已核对的 `PARAMDT` 参数中，暂未找到一个既能从 SD 导入、又能由原厂照片成像路径读取的颜色参数 ID。E-P5 可通过原厂照片模式和 Myset 做机内配方。两条路径各有可复查的使用范围。

## SD 参数与成像字段的对应

核对输入为 E-P5 1.8 解码 MAIN，CPU 基址 `0x7e101020`，SHA-256 为 `dfe255e4d5a43329712c1fdfd6861ee1f3ef54a268b6096628bf045d8cc590df`。该固件的参数导入会建立 RAM 覆盖索引，记录预算为 8,188 字节（含记录头和对齐）。未压缩的 17³ RGB16 色表数据为 29,478 字节。即使采用更小的表示，也需要一条能解释该格式并将结果传到照片成像的路径。[参数导入审计](LUT_RUNTIME_AUDIT.md)

| 已核对的候选 | 原厂读取路径 | 结论 |
|---|---|---|
| `0xF971`，现有 CSV 模型的参数 ID | `0x7e1c8214` 装入 `0xF971`，`0x7e1c821d` 调参数读取 `0x7e141667`，结果用于无线调试初始化分支。 | 能验证解析、覆盖、读取和清除。当前已确认的消费者属于无线调试启动。 |
| `chContrast`、`chTone`、`chSaturation` | `0x7e3ed246..0x7e3ed25d` 从拍摄上下文 `+17442/+17444/+17468` 复制到 ART packet `+157/+158/+160`。`0x7e409cc9..0x7e409cdd` 再复制到工作记录 `+0x55/+0x56/+0x58`。饱和度先按半字写入 packet，再按字节写入工作记录。 | 这些数字是结构内偏移。已确认两次复制，但尚未建立 `PARAMDT` 参数 ID 到拍摄上下文的上游连接。 |
| 针孔 I 的原生 Cb/Cr 色度表 | 原厂模式分派分支 `0x7e22a12f` 在 `0x7e22a131/0x7e22a152` 取两个固定 MAIN 地址 `0x7e438bb0/0x7e438be1`。两表各 49 字节。柔彩 RC2 修改了这些表并取得实机成片证据。 | 已查到表的实际成像作用。这个分支直接装入表地址，尚未发现查找或读取 SD 覆盖参数 ID 的连接。 |

上述三个颜色片段（设置复制从 `0x7e3ed0c5` 起查至 `0x7e3ed275`）分别核对了原始字节，并交叉检查对 `0x7e140c57`、`0x7e141654`、`0x7e141667`、`0x7e141689` 的直接调用。在这几个区间内没有找到对应调用。用同样方法可在无线初始化片段找到 `0x7e1c821d → 0x7e141667`。这个检查只覆盖指定范围，完整调用者、其他参数读取入口及间接调用仍需各自取证。[原厂颜色字段](T2_NATIVE_PATHS.md) · [色度表选择器](ART_SLOT_AUDIT.md) · [实机成片](SOFT_CHROME.md)

## 原厂机内配方

| 要调的内容 | 机身操作及范围 |
|---|---|
| 基础色彩与反差 | 拍摄菜单 1 的「影像模式」可选 Natural、Muted、Portrait、Vivid 或自定义等。按方向键向右进入细项，按对应模式支持的范围调对比度、清晰度、彩度和灰阶。黑白模式有黑白滤镜和色调设置。 |
| 白平衡与影调 | 固定白平衡后可细调，再按需要用高光／阴影控制调整明暗。自定义菜单允许选择 JPEG 色彩空间。色域设置与照片模式的创意调色分别控制。 |
| 机身保存与切换 | 拍摄菜单 1 的「重设／自定义设定」（Myset）可登记四套设置，在 P/A/S/M 调用。选择已占用的槽并登记会覆盖旧设置，手册的菜单索引逐项标记可存哪些设置。 |
| 同源色彩比较 | 最大尺寸、4:3、RAW+JPEG 可在同次拍摄保存 4608×3456 JPEG 和 ORF。回放选「RAW 编辑 → 当前设置」可从同一 ORF 另存 JPEG，适合比较各项原厂配方。 |

### 可手动试拍的四组起始值

下列数值是给原厂 E-P5 的手动配方建议，尚未经这台机身校色。每组使用独立的基础影像模式，方便比较。先固定现场白平衡，把灰阶设为标准，记录现有设置。在「影像模式」按右键调整对比度和彩度。高光／阴影在拍摄时调出曝光补偿，再按 INFO 切换。最后按需将设置登记到空闲 Myset。登记在已有内容的位置会覆盖旧配置。

| 想要的画面 | 影像模式 | 对比度 / 彩度 | 高光 / 阴影 | 白平衡微调 |
|---|---|---|---|---|
| Gold 方向，暖色日常 | Natural | 0 / +1 | −1 / +1 | 向琥珀色一档 |
| Portra 方向，低反差人像 | Portrait | −1 / −1 | −2 / +2 | 中性，按现场光固定 |
| Velvia 方向，浓郁风景 | Vivid | +1 / +1 | 0 / −2 | 中性，按现场光固定 |
| 森山大道方向，高反差黑白 | Monotone | +2 / 不适用 | +1 / −2 | 黑白滤镜先用中性 |

同一 ORF 分别用上述设置另存 JPEG，暖色重点对照灰物与肤色，低反差看暗发与衣物中的细节，浓郁色看红色是否丢失层次。黑白配方只用反差塑造影调。颗粒、分区色相与 SD 表的效果须分别比较。这四组可以在原厂机身上录入，和开发用三维 LUT 数据包是两种使用方式。

## 复跑范围

`python tools/audit_lut_runtime.py` 核对固定 MAIN、记录预算和参数服务位置。用 WSL 的 `python3 -m unittest discover -s tests -p test_native_probe.py -v` 复跑，3 项通过。测试使用合成基础参数、栈和 RAM，执行覆盖的解析、安装、读取和清除。彩色字段和色表地址由固定 MAIN 的指令字节与既有探针报告交叉核对。项目后续若找到新的成像候选，应先把同一次的覆盖 ID、读取调用和流向成像的具体字段放进一个测试，再比较开启及取消覆盖时的输出。
