# E-P5 SD 风格数据

优先使用 [EP5-Personal-32-FX2.zip](EP5-Personal-32-FX2.zip)。它收录 29 款 Caduceus 彩色配方，加上森山风高反差黑白、Tri‑X 和 Acros。只需要彩色配方时可选 29 款包。两个 FX2 包都包含 Atrophy 的局部清晰度。用同一幅全尺寸输入验证，旧版与新版共 32 款中只有 Atrophy 的输出改变。三个组共用一个 `EP5LUT` 目录。原厂 E‑P5 1.8 和固定 ART 版目前都不能直接读取这些数据。见[全尺寸处理记录](../docs/EP5_SD_PHOTO.md)。
