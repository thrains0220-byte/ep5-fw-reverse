This spreadsheet used to provide the locations to download the OM and Olympus camera firmware. Unfortunately, as of December 20th, 2025, firmware files are no longer available as downloads without using something like the shell script below. Now, it just provides the instructions on how to update the firmware assuming you can get the firmware from some other location, giving the name of the file to rename the firmware to on the memory card (SD, micro-SD, CF, or Xd cards).

To install the firmware:
25
26
1:Mount the SD/CF/XD card on your computer.
27
2:Create a folder on the SD/CF/XD named 'DCOLYMP' using captial letters.
28
3:Download the appropriate file from the internet.
29
4:Copy the file to the name specified in the 'Name in DCOLYMP directory' column to the 'DCOLYMP' directory.
30
5:Turn off your camera
31
6:Be sure to fully charge the camera's batteries before you start.
32
7:Unmount the card from the computer, and put it in the camera.
33
8:If your camera has 2 card slots, use the first card slot. The OM-1 and E-m1 mark II require the SD card to be in the top slot. On the E-5, the firmware can be in the SD card slot in addition to the CF card slot.
34
9:If you are using SD cards on older cameras, use a SD card that is 32 gigabytes or smaller. The oldest camera that I have that uses SD cards is the E-P2 that was released in 2009. The E-P2 does not support 64 gigabyte cards or larger, and the firmware must be on a 32 gigabyte crd or smaller using the FAT32 file system. My newer cameras, starting with the E-5 (announced in 2010) can load their firmware from 64 gigabyte cards or larger using the exFat file system.
35
36
37
10:Start the camera while pressing the OK button
38
11:The screen will go black and the focus assist LED will turn on steady.
39
12:DO NOT TURN OFF THE CAMERA WHILE THE FOCUS ASSIST LIGHT IS ON STEADY
40
13:Wait until the focus assist light blinks rapidly.
41
14:When the focus assist light blinks rapidly, turn off the camera.
42
15:When you turn on the camera, it should have the new firmware installed.
43
16:You might want to remove the 'DCOLYMP' directory from the SD/CF/Xd card.
44
17:This method is only for updating the body firmware. You must use the official methods to update the firmware of lenses.
45
18:Since each camera's firmware has a unique name (based on the camera internal model number), you can create a SD/CF/Xd card with firmware for all of your cameras on a single card. As I understand it, this is used by OM Systems (and Olympus before that) service personal to update any camera to the current firmware. As of November 4th, 2025, the total size for all current firmware files is 3.1 gigabytes.
