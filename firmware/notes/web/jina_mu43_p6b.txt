I updated my version 1.7 om1 today to version 1.9. I was worried because of all the stories but found the process to be simple and fast. Just put a fresh battery in the camera, connect to computer via cable, open up the OM system software on computer, select camera then update, and follow the instructions. The only (brief) issue I had was getting computer and camera to connect but chat gpt explained to me the camera menu setting to use. In 10 minutes I was done. I was also able to easily mirror the settings on my existing camera to a new one (used) just received by using the OM system software. Note this only works for two of the exact same cameras. Just select camera then save to get settings into computer, then camera and load to get them on second camera.

I have written a bash script to **easily** download OM firmware on Linux. You then have to use the SD card installation method. See [https://docs.google.com/spreadsheets/d/10vaBZZrfVLeotlAjfGy5Vo_qtelXevRkdPMBd-VN53k/edit?gid=0#gid=0](https://docs.google.com/spreadsheets/d/10vaBZZrfVLeotlAjfGy5Vo_qtelXevRkdPMBd-VN53k/edit?gid=0#gid=0)  
 To use the script, copy it to a file such as om-download.sh. Then edit the line CAMERA_CODE= to select your camera type. The type codes can be found in the above link. Then run the script. Let me know if there are any problems!

Bash:

```
#! /bin/bash
#
# Download Olympus firmware
#
# Note: Make sure you have the following programs installed:
#       curl
#       wget
#       xmllint
#
# Edit the CAMERA_CODE line below to suit your camera before running the script
#
# Refer to the spreadsheet with Camera codenames & firmware filenames:
#    https://docs.google.com/spreadsheets/d/10vaBZZrfVLeotlAjfGy5Vo_qtelXevRkdPMBd-VN53k/edit?gid=0#gid=0
# Use the first 4 characters of the "SD/CF/Xd name" for your camera
# Eg: E146 for OM-1 Mark II

CAMERA_CODE=E146

# This seems to be ignored by the OM server, so shouldn't need changing.
# If there is a problem, try setting it to your camera's serial number.
CAMERA_SERIAL=V5PF30000

# The directory to download to
DOWNLOAD_DIR=/tmp

# *** There should be no need to change anything below here ***

REPLY_FILE=om-reply.xml
SD_FILE=${CAMERA_CODE}9999.BIN

cd $DOWNLOAD_DIR
rm -f $REPLY_FILE

echo "Finding download file ..."
curl --ssl-no-revoke --no-progress-meter --user-agent "Olympus" --header "Content-Type: text/xml; Charset=UTF-8" --data "@-" https://fw01.om-digitalsolutions.net/ww_inform/fcache.do --output $REPLY_FILE << EOF
<?xml version="1.0"?>
<firmware_demand>
<revision>0001</revision>
<mac_address>00-00-00-00-80-D6</mac_address>
<time>`date +%Y%m%d%H%M%S`</time>
<language>ENU</language>
<application>FWUT</application>
<type>0000</type>
<version>00005000</version>
<os>WIN</os>
<country_code>0001</country_code>
<hardwares>
<firmup_mode>0</firmup_mode>
<hardware_info>
<hard_code>OLY${CAMERA_CODE}000000000</hard_code>
<firmware_version>00001000</firmware_version>
<serial_no>$CAMERA_SERIAL</serial_no>
<default_languages>
<code>JPN</code><code>ENU</code><code>DEU</code><code>FRA</code><code>ESP</code>
<code>CHS</code><code>CHT</code><code>KOR</code><code>PTG</code><code>ITA</code>
<code>RUS</code><code>CSY</code><code>NLD</code><code>SVE</code><code>DAN</code>
<code>NOR</code><code>FIN</code><code>HRV</code><code>SLV</code><code>HUN</code>
<code>PLK</code><code>ELL</code><code>SKY</code><code>TRK</code><code>LVI</code>
<code>ETI</code><code>LTH</code><code>UKR</code><code>SRB</code><code>THA</code>
<code>BGR</code><code>IND</code><code>MSL</code><code>ROM</code>
</default_languages>
</hardware_info>
</hardwares>
</firmware_demand>
EOF
STATUS=$?
if [ $STATUS -ne 0 ]; then
        echo "*** ERROR:" >&2
        cat $REPLY_FILE >&2
        exit $STATUS
fi

URL=`xmllint --xpath 'string(//url)' $REPLY_FILE`
FILENAME=`xmllint --xpath 'string(//file_name)' $REPLY_FILE`
CAMERA_MODEL=`xmllint --xpath 'string(//model_name)' $REPLY_FILE`
if [ -z "$URL" -o -z "$FILENAME" -o -z "$CAMERA_MODEL" ]; then
        echo "No firmware found for camera code $CAMERA_CODE" >&2
        exit 1
fi
FILESIZE=`xmllint --xpath 'string(//file_size)' $REPLY_FILE`
echo
echo "Downloading $FILENAME for $CAMERA_MODEL into $DOWNLOAD_DIR..."
wget --quiet --show-progress -O $FILENAME $URL
if [ $? -ne 0 ]; then
        echo "Download failed" >&2
        exit 1
fi
echo "Download complete"
echo
if [ `stat -c%s $FILENAME` -ne $FILESIZE ]; then
        echo "The downloaded file seems corrupted" >&2
        echo "Filesize expected to be $FILESIZE" >&2
        exit 1
fi
echo "Renaming to $SD_FILE"
mv $FILENAME $SD_FILE || exit 1
cat <<- EOF

Your firmware file has been downloaded to $SD_FILE (in $DOWNLOAD_DIR).

Now create a folder DCOLYMP on your SD card and copy $SD_FILE there.
To install the new firmware, load the SD card into your $CAMERA_MODEL and
turn on the camera holding the OK button.

Disclaimer: This script only downloads the firmware file to your computer.
You are responsible for the correct firmware installation on your camera!
Make sure that you battery is full and that the installation is not
interrupted.
EOF
exit 0
```

In addition to the above, here is an even easier to use version of the script to download OM firmware on Linux. Just run the script and enter your camera model.

Bash:

```
#! /bin/bash
#
# Download Olympus firmware
#
# By Michael Selig, Feb 2026
#
# Note: Make sure you have the following programs installed:
#    curl
#    wget
#    xmllint
#
# Refer to the spreadsheet with Camera codenames & firmware filenames:
#    https://docs.google.com/spreadsheets/d/10vaBZZrfVLeotlAjfGy5Vo_qtelXevRkdPMBd-VN53k/edit?gid=0#gid=0
# Use the first 4 characters of the "SD/CF/Xd name" for your camera
# Eg: E146 for OM-1 Mark II

# The camera's serial number seems to be ignored by the OM server, so
# shouldn't need setting.
# If there is a problem, try setting it to your camera's serial number.
CAMERA_SERIAL=V5PF30000

# The OM server URL to query
OM_URL=https://fw01.om-digitalsolutions.net/ww_inform/fcache.do

# List of camera and their codes
CAMERAS=(
    E143    "OM-1 Mark I"
    E146    "OM-1 Mark II"
    E147    "OM-3"
    E144    "OM-5 Mark I"
    E134    "E-M1X"
    E109    "E-M1 Mark I"
    E125    "E-M1 Mark II"
    E139    "E-M1 Mark III"
    E097    "E-M5 Mark I"
    E118    "E-M5 Mark II"
    E137    "E-M5 Mark III"
    E113    "E-M10 Mark I"
    E120    "E-M10 Mark II"
    E130    "E-M10 Mark III"
    E140    "E-M10 Mark IV"
    E068    "E-P1"
    E070    "E-P2"
    E085    "E-P3"
    E108    "E-P5"
    E142    "E-P7"
    E074    "E-PL1"
    E088    "E-PL1S"
    E086    "E-PL3"
    E100    "E-PL5"
    E112    "E-PL6"
    E115    "E-PL7"
    E126    "E-PL8"
    E133    "E-PL9"
    E042    "E-3"
    E079    "E-5"
    E111    "Stylus 1"
    E106    "TG-2"
    E121    "TG-4"
    E129    "TG-5"
    E145    "TG-7"
    E122    "PEN-F"
)

NUM_CAMERAS=$((${#CAMERAS[@]} / 2))

echo
echo "*** OM Firmware downloader ***"
echo

# Check that certain programs are installed
if ! command -v curl > /dev/null 2>&1; then
    echo "*** ERROR: Cannot find CURL. Please install it." >&2
    exit 1
fi
if ! command -v wget > /dev/null 2>&1; then
    echo "*** ERROR: Cannot find WGET. Please install it." >&2
    exit 1
fi
if ! command -v xmllint > /dev/null 2>&1; then
    echo "*** ERROR: Cannot find XMLLINT. Please install it." >&2
    exit 1
fi

# Prompt for camera
echo "Please select your camera model:"
echo
i=1
while [ $i -le $NUM_CAMERAS ]; do
    printf "%2d: %-20s" $i "${CAMERAS[$((i*2 - 1))]}"
    [ $((i++ % 3)) = 0 ] && echo
done
[ $((i % 3)) != 1 ] && echo
echo -n "Enter the number for your camera [1..$NUM_CAMERAS]: "
read NUM
if [ -z "$NUM" -o "$NUM" -le 0 -o "$NUM" -gt $NUM_CAMERAS ]; then
    echo "*** ERROR: The camera number must be between 1 and $NUM_CAMERAS" >&2
    exit 1
fi
CAMERA_CODE=${CAMERAS[$((NUM * 2 - 2))]}
CAMERA_MODEL=${CAMERAS[$((NUM * 2 - 1))]}
echo "*** You have selected $CAMERA_MODEL (code $CAMERA_CODE)"
echo

# Prompt for download directory
echo -n "Enter the directory to download to [default: current directory]: "
read DOWNLOAD_DIR
if [ -n "$DOWNLOAD_DIR" ]; then
    if [ ! -d "$DOWNLOAD_DIR" ]; then
    echo "*** ERROR: Directory $DOWNLOAD_DIR does not exist" >&2
    exit 1
    fi
    if [ ! -w "$DOWNLOAD_DIR" ]; then
    echo "*** ERROR: You do not have write access to Directory $DOWNLOAD_DIR" >&2
    exit 1
    fi
fi

REPLY_FILE=om-reply.xml
SD_FILE=${CAMERA_CODE}9999.BIN

[ -n "$DOWNLOAD_DIR" ] && cd $DOWNLOAD_DIR
rm -f $REPLY_FILE

echo -n "Finding download file ..."
curl --ssl-no-revoke --no-progress-meter --user-agent "Olympus" --header "Content-Type: text/xml; Charset=UTF-8" --data "@-" $OM_URL --output $REPLY_FILE << EOF
<?xml version="1.0"?>
<firmware_demand>
<revision>0001</revision>
<mac_address>00-00-00-00-80-D6</mac_address>
<time>$(date +%Y%m%d%H%M%S)</time>
<language>ENU</language>
<application>FWUT</application>
<type>0000</type>
<version>00005000</version>
<os>WIN</os>
<country_code>0001</country_code>
<hardwares>
<firmup_mode>0</firmup_mode>
<hardware_info>
<hard_code>OLY${CAMERA_CODE}000000000</hard_code>
<firmware_version>00001000</firmware_version>
<serial_no>$CAMERA_SERIAL</serial_no>
<default_languages>
<code>JPN</code><code>ENU</code><code>DEU</code><code>FRA</code><code>ESP</code>
<code>CHS</code><code>CHT</code><code>KOR</code><code>PTG</code><code>ITA</code>
<code>RUS</code><code>CSY</code><code>NLD</code><code>SVE</code><code>DAN</code>
<code>NOR</code><code>FIN</code><code>HRV</code><code>SLV</code><code>HUN</code>
<code>PLK</code><code>ELL</code><code>SKY</code><code>TRK</code><code>LVI</code>
<code>ETI</code><code>LTH</code><code>UKR</code><code>SRB</code><code>THA</code>
<code>BGR</code><code>IND</code><code>MSL</code><code>ROM</code>
</default_languages>
</hardware_info>
</hardwares>
</firmware_demand>
EOF
STATUS=$?
if [ $STATUS -ne 0 ]; then
    echo
    echo "*** ERROR:" >&2
    cat $REPLY_FILE >&2
    exit $STATUS
fi

URL=$(xmllint --xpath 'string(//url)' $REPLY_FILE)
FILENAME=$(xmllint --xpath 'string(//file_name)' $REPLY_FILE)
CAMERA_MODEL=$(xmllint --xpath 'string(//model_name)' $REPLY_FILE)
if [ -z "$URL" -o -z "$FILENAME" -o -z "$CAMERA_MODEL" ]; then
    echo
    echo "*** ERROR: No firmware found for camera code $CAMERA_CODE" >&2
    exit 1
fi
echo " OK"

FILESIZE=$(xmllint --xpath 'string(//file_size)' $REPLY_FILE)
echo
echo "Downloading $FILENAME for $CAMERA_MODEL${DOWNLOAD_DIR:+ into $DOWNLOAD_DIR} ..."
wget --quiet --show-progress -O $FILENAME $URL
if [ $? -ne 0 ]; then
    echo "Download failed" >&2
    exit 1
fi
echo "Download complete"
echo
if [ $(stat -c%s $FILENAME) -ne $FILESIZE ]; then
    echo "*** ERROR: The downloaded file seems corrupted" >&2
    echo "Filesize expected to be $FILESIZE" >&2
    exit 1
fi
echo "Renaming to $SD_FILE"
mv $FILENAME $SD_FILE || exit 1
cat <<- EOF

Your firmware file has been downloaded to $SD_FILE${DOWNLOAD_DIR:+ (in $DOWNLOAD_DIR)}.

Now create a folder DCOLYMP on your SD card and copy $SD_FILE there.
To install the new firmware, load the SD card into your $CAMERA_MODEL and
turn on the camera holding the OK button.

See https://docs.google.com/spreadsheets/d/10vaBZZrfVLeotlAjfGy5Vo_qtelXevRkdPMBd-VN53k/edit?gid=0#gid=0
for more details.

Disclaimer: This script only downloads the firmware file to your computer.
You are responsible for the correct firmware installation on your camera!
Make sure that you battery is full and that the installation is not
interrupted.
EOF
exit 0
```
