Olympus/OM System
Unofficial firmware download

About

This page allows you to download the latest firmware for Olympus/OM System cameras to your computer to install it offline via a SD/CF/XD card following the procedure detailed bellow.

It may also help you in case your camera is bricked while performing an official upgrade.

This method is only for updating the body firmware. You must use the official methods to update the firmware of your lenses.

The file for the latest version is downloaded directly from Olympus/OM System servers, this page just streamlines the process since direct access to the files is not possible anymore.

Files for older firmware versions are downloaded from a local copy. Again, direct access to the files directly from Olympus/OM System is not possible.

The main source of information for this page comes from the excel file mantained by mu-43.com member Michael Meissner and the information provided in this thread.

I'm collecting old firmware versions of all Olympus/OM System cameras to make this page a public and permanent archive. So if you happen to have an old firmware version not listed here, please contact me.

Step by step guide

Step 1: Download the firmware

Choose your camera model an download the file to your computer

Step 2: Prepare the card
  1. Mount the SD/CF/XD card on your computer.
  2. Create a folder in the card named DCOLYMP using captial letters.
  3. Copy in the DCOLYMP directory the downloaded file
  4. Unmount the card from the computer.
Step 3: Prepare the camera
  1. Be sure to fully charge the camera's batteries before you start.
  2. Turn off your camera.
  3. Put the card in the camera.
  4. If your camera has 2 card slots, use the first card slot.
    • The OM-1 and E-m1 mark II require the SD card to be in the top slot.
    • On the E-5, the firmware can be in the SD card slot in addition to the CF card slot.
  5. If you are using SD cards on older cameras, use a SD card that is 32 gigabytes or smaller.
Step 4: Perform the upgrade
  1. Start the camera while pressing the OK button.
  2. The screen will go black and the focus assist LED will turn on steady.
  3. Stop pressing the OK button.
  4. DO NOT TURN OFF THE CAMERA WHILE THE FOCUS ASSIST LIGHT IS ON STEADY
  5. Wait until the focus assist light blinks rapidly.
  6. When the focus assist light blinks rapidly, turn off the camera.
  7. The update has finished, when you turn on the camera, it should have the new firmware installed.
  8. You might want to remove the 'DCOLYMP' directory from the SD/CF/XD card.
