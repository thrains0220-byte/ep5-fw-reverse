# E-P5 1.8 模式 / 滤镜数据表总览（第十二轮收尾）

> 日期：2026-10-22
> 性质：静态观察
> 作用：把「菜单 → 效果 → ROM 参数块」三层数据表的**坐标**全部固定下来，
> 供后续"新增滤镜 / 解锁"直接使用。

## 1. 三张已定位的数据表

| # | 表 | 地址（运行时） | 文件偏移 | 内容 |
|---|---|---|---|---|
| T1 | **照片模式菜单资源 ID 列表** | `0x40E2F73E` | `0xB6F73E` | `[63,64,65,66,67,68,69,70,71,72, 50]` = `A03F..A048` + 尾值 50 |
| T2 | **图片模式 ROM 参数块表** | `0x40A56338` | `0x796338` | **20 槽**（前 10 = 拍照，后 10 = 录像），**9 个不同 ROM 块**，`0x7E5C9194` = 默认 |
| T3 | **艺术效果参数区** | `0x605FCD44` | （RAM） | 312 B 当前生效参数 |
| T3b | 效果 50 参数模板 | `0x605FCE7C` | （RAM） | 312 B，与 T3 相隔 `0x138` |

### T1 原文

```
file 0x00B6F73E:  3F 00 40 00 41 00 42 00 43 00 44 00 45 00 46 00 47 00 48 00 32 00
                   A03F  A040  A041  A042  A043  A044  A045  A046  A047  A048  50
```

⇒ **10 个照片模式菜单项的资源 ID 连续 A03F–A048**（与 §2 菜单一一对应），
尾随的 `50` 是表尾/关联值。

### T2 原文（20 槽）

```
槽  0- 9 : 9171 9194 913E 918F 9194 9194 9194 9169 9194 9194
槽 10-19 : 9142 9185 9194 9194 9146 9194 9194 918A 916D 9194
                   （低 16 位，页基址 0x7E5C9000；0x7E5C9194 = 默认/无效果，出现 11 次）
```

**按「同一下标 = 同一模式的拍照/录像两种形态」解读**：

| 模式下标 | 拍照块 | 录像块 | 形态可用性 |
|---|---|---|---|
| 0 | 9171 | 9142 | 两种都有 |
| 1 | 9194 ★ | 9185 | **仅录像** |
| 2 | 913E | 9194 ★ | **仅拍照** |
| 3 | 918F | 9194 ★ | **仅拍照** |
| 4 | 9194 ★ | 9146 | **仅录像** |
| 5 | 9194 ★ | 9194 ★ | 两种都无（默认） |
| 6 | 9194 ★ | 9194 ★ | 默认 |
| 7 | 9169 | 918A | 两种都有 |
| 8 | 9194 ★ | 916D | **仅录像** |
| 9 | 9194 ★ | 9194 ★ | 默认 |

⇒ **4 个"仅拍照"形态 + 5 个"仅录像"形态**，共 9 个非默认 ROM 块。
**这与艺术滤镜的形态分布一致**：
- 照片侧艺术效果：`art_filter_rough_monochrome`(NN06) / `art_diorama`(NN09) /
  `art_filter_dramatic_tone`(NN14) / `art_artclearline`(NN19) / `art_pastel_art`(NN21) —— **5 个**
- 录像侧艺术效果：`art_effect_10_star_light` / `20_pinhole` / `30_frame` /
  `40_soft_focus` / `50_white_edge` —— **5 个**

> ⚠️ 槽位与具体效果的**逐项对应尚未测定**（下标 0–9 与 10 个照片模式名的次序对应关系
> 需要 §3 的装载函数来确认）。**"仅录像形态"的存在已被 T2 直接证实**，
> 这为"解锁电影艺术滤镜"提供了数据层依据。

## 3. 艺术层 ROM 参数装载（类型 1 = 拍照 / 2 = 录像）

`FUN_407892D7`（类型分派器）：

```c
uVar1 = (uint)*param_1;
if      (uVar1 == 1) uVar1 = FUN_40789200(...);   /* ROM 0x7E5C9D1E -> RAM 0x605FD1B0 */
else if (uVar1 == 2) uVar1 = FUN_40789285(...);   /* ROM 0x7E5C9E0E -> RAM 0x602AEBC4 */
```

| ROM 源 | RAM 目标 | 角色 | 引用位置(file) |
|---|---|---|---|
| `0x7E5C9809` | `0x605FCA00` | 拍照效果参数源（类型初始化） | `0x4C862C` |
| `0x7E5C9B1C` | `0x605FCCC4` | 录像效果参数源（类型初始化） | `0x4C863F` |
| `0x7E5C9D1E` | `0x605FD1B0` | 类型 1（拍照）装载源 | `0x4C9235` |
| `0x7E5C9E0E` | `0x602AEBC4` | 类型 2（录像）装载源 | `0x4C929E` |
| `0x7E5CA4EC` | `0x605FCCBC` | 效果控制块 | `0x4C930D` |
| `0x7E5CA6E7` | — | 效果查询 | `0x4C96A7` |
| `0x7E5CA71B` / `0x7E5CA74F` | — | 效果查询（同一函数） | `0x4C9643` / `0x4C964F` |

装载函数都会把 **6 字节**（`param_2 + 5` 起，逆序）拷到 `0x605FD224`
⇒ 这 6 字节应是**效果的调校/识别码**。
